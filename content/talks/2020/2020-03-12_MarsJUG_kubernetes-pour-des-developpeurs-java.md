Que peut faire un développeur Java dans un monde où les containers et Kubernetes semblent avoir remplacé les stacks Java et JEE traditionnelles? Comment la JVM peut-elle rivaliser avec les containers ultrarapides et légers d’autres piles? Java est-il condamné à devenir le prochain COBOL?

N’ayez plus peur, la communauté Java a bien compris ce nouveau monde courageux et des solutions sont disponibles.

Dans cet exposé, je parlerai de GraalVM, une JVM ultrarapide, polyglotte, légère, compilant en natif. Avec GraalVM vous pourrez compiler vos applications Java en binaires natifs petits et performants, d’une façon simple et indolores. Vous pourrez ensuite déployer ces binaires dans des containers Docker ou d’autres, et rivaliser en performance avec n’importe quelle stack Cloud Native.

Je parlerai ensuite de Quarkus et de la façon dont vous pouvez le combiner avec GraalVM pour créer de puissantes applications Java, de manière moderne.
